# Security Policy

## Supported Versions

Security fixes are currently handled on the default branch until the project starts publishing
versioned releases.

## Reporting A Vulnerability

Please report security issues privately to the project maintainer before opening a public issue.
If this repository is hosted on GitHub, use GitHub's private vulnerability reporting feature when
enabled, or contact the repository owner through their published profile contact method.

Do not include live credentials, GitHub tokens, database passwords, or private repository data in
public issues.

## Credentials

Each user must provide their own GitHub token through a local `.env`, shell environment, or private
MCP client configuration. Real tokens must never be committed to this repository.
